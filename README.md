# cooling-telemetry-monitor

Программная часть ИС мониторинга аппаратной телеметрии систем охлаждения
вычислительного узла. Лабораторные работы № 1–2 по дисциплине
«Программное и аппаратное обеспечение ИС», ЮФУ, группа КТмо 1-12.

## Что уже есть (ЛР1)

- Архитектура C++17/Qt-приложения: генератор телеметрии, DSP-фильтрация,
  AES-256, PostgreSQL.
- UML-диаграммы (вариантов использования, состояний, последовательности),
  функциональная схема, диаграмма модулей, схема БД.
- Канбан-доска Trello.

## Что добавлено в ЛР2

- `ISensorSource` — единый интерфейс аппаратного и модельного датчика.
- `ModelSensor` — тепловая модель Ньютона-Рихмана с шумом, джиттером
  и 12-битным квантованием АЦП.
- `RingBuffer<T, N>` — кольцевой буфер SPSC без блокировок.
- `Sampler` — сетка выборки 100 Гц с компенсацией ухода часов.
- `EmaFilter`, `MovingAverage`, `FilterChain` — предварительная обработка.
- `AcquisitionPipeline` — сборка конвейера «источник → буфер → выборка →
  фильтрация → потребитель».
- Модульные тесты и режим верификации DSP с экспортом CSV.

## Сборка

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build --output-on-failure
```

## Запуск

```bash
# реальное время: 30 с, 100 Гц, статистика в stderr
./build/ctm_acq --duration 30 --fs 100

# верификация DSP с экспортом данных для графиков
./build/ctm_acq --verify --duration 60 --csv telemetry.csv
```

## Структура

```
include/ctm/   публичные заголовки библиотеки
src/           реализация блоков и демонстрационная программа
tests/         модульные тесты без внешних зависимостей
docs/          проектные заметки ЛР1/ЛР2
tools/         построение графиков по CSV
```

## Ветвление

`main` — защищённая ветка, `develop` — интеграция, `feature/*` — задачи.
История коммитов ведётся в формате Conventional Commits.
