# Лабораторная работа № 1: исходная архитектура

Документ фиксирует решения, принятые в ЛР1, чтобы ЛР2 не меняла проект
целиком, а расширяла его.

## Назначение системы

Мониторинг температуры процессора и оборотов кулеров вычислительного узла,
цифровая фильтрация показаний, шифрование AES-256 и сохранение в PostgreSQL.

## Слои

| Слой | Компонент ЛР1 | Файл/модуль |
|---|---|---|
| Представление | GUI на Qt | `ui/` (ЛР1) |
| Генерация данных | Эмулятор датчиков | `ModelSensor` |
| Обработка | DSP-фильтрация EMA | `EmaFilter` |
| Защита | AES-256 | `crypto/` (ЛР1) |
| Хранение | PostgreSQL, libpqxx | `db/` (ЛР1) |

## Модель сигнала

Закон охлаждения Ньютона-Рихмана:

```
T(t+dt) = T(t) + (T_target(t) - T(t)) * (1 - exp(-dt / tau))
T_measured = quantize(T(t) + ripple(t) + N(0, sigma))
```

Параметры: `tau = 8 с`, период нагрузки `45 с`, `sigma = 0.45 °C`,
АЦП 12 бит, диапазон `0…120 °C`.

## Связь с ЛР2

ЛР2 сохраняет модель, интерфейс Qt и схему БД. Добавляется транспортный
слой: источник сигнала, буфер, дискретизация и конвейер фильтрации.
